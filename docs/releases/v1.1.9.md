# Niven Ringworld Expedition v1.1.9

This update fixes the missing ring/control-panel problem in affected modded installations and improves aircraft, drilling and water compatibility on the ringworld.

## Startup and mod compatibility

- Fixed a startup conflict with KSP Community Fixes that could prevent the ring and its Flight control button from appearing. Addresses [issue #6](https://github.com/theplatecrafter/Ring-World-KSP-mod/issues/6).
- Fixed repeated compatibility setup during scene changes, which could cause a second air-intake error after the initial startup failure.
- If an optional integration cannot load, the ring and controls remain available and a visible warning identifies the affected feature. Errors affecting essential flight handling block unsafe ring flight to protect saved craft.

## Aircraft, resources and water

- Improved AJE/SolverEngines support for the ring's atmosphere, including air intakes and jet-engine inlet conditions.
- Corrected the airspeed reported to stock parts and AJE/SolverEngines. It now reflects motion relative to the ring's surface, avoiding the enormous speeds relative to the host star that could produce unrealistic inlet temperatures.
- Ring drills now use local resource abundance correctly when KSP Community Fixes' resource optimization is enabled, instead of receiving cached values for the host star.
- Fixed ring-water buoyancy being skipped by KSP Community Fixes' ocean checks. The host star's atmosphere and ocean properties remain unchanged.

## Updating and existing saves

Back up your saves, extract the ZIP into the KSP root, merge `GameData` and **replace matching files**, then restart KSP. Keep your existing configuration pack and extension folders.

These fixes do not require a new save or deleting the Ringworld scenario. Existing saved ring layouts, terrain settings and expedition progress are preserved. The control panel remains available in Flight and flight Map View; the ring also renders in the Space Center and Tracking Station.

## Requirements and optional extensions

KSP 1.12.5, Windows x64 / Direct3D 11. Required dependencies remain **Harmony 2 >= 2.2.1.0** and **ModuleManager >= 4.0.0**, installed separately. CKAN installations select one Ringworld configuration pack; interstellar packs additionally require Kopernicus and its dependencies. Keep only one replacement configuration pack installed.

Existing Ringworld Clouds 1.0.1, Ringworld Scattering 1.0.2 and Ringworld Parallax 1.0.0 remain compatible; no extension update is needed for this base-mod fix. Cyla 1.1.0 remains optional. This update adds no new required mods, and the base ZIP does not bundle dependencies or extensions.

## Validation

Targeted in-game checks passed with KSP Community Fixes 1.41.1, AJE 2.20.0, RealFuels 15.14 with RF-Stock 5.1.0, FAR 0.16.1.2 and B9 Part Switch 2.21.0. These covered startup, Tracking Station transitions, save reopening, drilling, intakes, buoyancy and an RF-configured aircraft engine burn. Older save-data loading and save/reload checks also passed, alongside all 110,644 core checks.

Testing used the Slow preset on Windows / Direct3D 11. Other aircraft, mod combinations, historical saves and graphics backends remain outside this test coverage.
